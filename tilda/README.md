# Встраивание сайта в Тильду

Сайт собирается в скрипт, стили и готовую разметку. Разметку вы вставляете в HTML-блоки Тильды, а скрипт и стили Тильда подгружает с хранилища (по умолчанию jsDelivr из репозитория на GitHub).

## Что вставлять

| Файл          | Куда вставлять                                           |
| ------------- | -------------------------------------------------------- |
| `head.html`   | Настройки сайта → Ещё → HTML-код для вставки внутрь HEAD |
| `header.html` | Страница **Header**: блок T123 «HTML»                    |
| `main.html`   | Главная страница: блок T123 «HTML»                       |
| `footer.html` | Страница **Footer**: блок T123 «HTML»                    |

Каждый файл вставляется целиком. Блок T123 находится в категории «Другое» → «HTML».

Файлы `head.html`, `header.html`, `main.html`, `footer.html` и папка `dist` создаются командой и руками не правятся.

## Как обновить

```
npm run build:tilda
```

Команда собирает `dist` и перезаписывает четыре файла. Дальше:

1. Закоммитьте и отправьте на GitHub папку `tilda/dist` вместе с файлами `tilda/*.html`.
2. Вставьте обновлённые файлы в Тильду и опубликуйте страницы.

В `footer.html` лежат подвал, нижняя панель быстрой связи и все окна (заявка, модели, ППУ, «Спасибо», юридические тексты). Окон на странице быть не должно, пока footer не вставлен.

## Где лежат файлы

Адрес хранилища задаётся в `config.json`:

- `assetsBase` — папка, откуда отдаются скрипт, стили, шрифты и фото. По умолчанию jsDelivr: `https://cdn.jsdelivr.net/gh/DenisKhairutdinov/typefl@main/tilda/dist/`.
- `siteUrl` — боевой адрес сайта, который заменяется в метаданных.

Свой хостинг тоже подойдёт: загрузите содержимое `tilda/dist` и впишите адрес папки в `assetsBase`. Сервер должен отдавать заголовок `Access-Control-Allow-Origin: *`, иначе шрифты, логотип и скрипт не загрузятся с другого домена.

jsDelivr кэширует ветку `main` до 12 часов. Чтобы обновление появилось сразу, откройте `https://purge.jsdelivr.net/gh/DenisKhairutdinov/typefl@main/tilda/dist/assets/app.js` и такой же адрес для `app.css`. Либо замените `@main` в `assetsBase` на тег или хэш коммита.

## Что настроить в Тильде руками

В `head.html` специально нет заголовка, описания и адреса: их задаёт сама Тильда. Заполните в настройках главной страницы → SEO:

- **Заголовок:** `Энергомаш: завод полуприцепов-цистерн и автоцистерн`
- **Описание:** `Производим полуприцепы-цистерны 28–38 м³, автоцистерны и автотопливозаправщики на КАМАЗ. Собственное производство, гарантия 12 месяцев, лизинг от 5%. КП с ценой за 1 рабочий день.`
- **Язык сайта:** русский.
- **Адрес страницы** и канонический адрес: `https://typefl.ru/`.

Чтобы сайт индексировался, в настройках сайта проверьте, что Тильда не закрывает страницы (`robots.txt` и `sitemap.xml` она генерирует сама). Файлы `robots.txt` и `sitemap.xml` из этой папки не используются.

## На что обратить внимание после вставки

- Скрипт сайта находит разметку по `data-` атрибутам, поэтому блоки нельзя менять местами или удалять их части. Если на странице нет `footer.html`, окна не откроются.
- Тильда добавляет свои стили и скрипты. Если что-то поехало (шапка, плавная прокрутка, шрифты), проверьте страницу в режиме просмотра, а не в редакторе: в редакторе скрипты сайта не запускаются.
- Заявки пока никуда не уходят. Форму нужно связать со скрытыми формами Тильды отдельным шагом.
