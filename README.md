# typefl

Лендинг завода автоцистерн и полуприцепов-цистерн «Энергомаш». Обычная фронтенд-вёрстка: HTML, CSS и JavaScript-модули, сборка Vite. Чистый JavaScript, без фреймворков и сторонних библиотек.

## Команды

| Команда            | Что делает                                |
| ------------------ | ----------------------------------------- |
| `npm run dev`      | Сервер разработки с горячей перезагрузкой |
| `npm run build`    | Сборка в `dist/`                          |
| `npm run preview`  | Показывает собранный сайт                 |
| `npm run lint`     | ESLint и Stylelint                        |
| `npm run lint:fix` | То же с автоисправлением                  |
| `npm run format`   | Форматирование Prettier                   |
| `npm run check`    | Формат, линтеры и сборка одной командой   |

## Структура

```
index.html         вся разметка страницы
src/
  main.js          точка входа: подключает стили и запускает страницу
  app.js           подключает поведение блоков
  config.js        номер счётчика, адрес приёмника заявок, страница «Спасибо»
  data/content.js  варианты первого экрана, продукты и шаги подбора
  behaviors/       подбор, фильтр моделей, формы, счётчики, подстройка первого экрана
  lib/             вспомогательные функции
  styles/          токены, база, кнопки, первый экран, секции, формы
docs/              аудит, структура, тексты, дизайн, план отслеживания
CLAUDE.md          правила работы над проектом
```

Модели страницы лежат в разметке как карточки с атрибутами `data-model-card`. Подбор читает их оттуда, поэтому список моделей хранится в одном месте.

Варианты первого экрана под группу объявлений включаются меткой `g` в адресе: `?g=atz`, `?g=ppc`, `?g=neft`, `?g=akn`, `?g=voda`.

## Правила

- Классы называются по БЭМ: `блок__элемент--модификатор`. Stylelint проверяет это.
- Движение отключается при настройке «уменьшить движение», новые анимации должны это учитывать.
- Страница работает и без скриптов: разметка и стили самодостаточны.
- Заявки пока никуда не отправляются, адрес приёмника задаётся в `src/config.js`.
