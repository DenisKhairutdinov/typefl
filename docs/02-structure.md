# Структура лендинга typefl.ru

Версия от 10 октября 2026. Заменяет прежний вариант на 26 страниц: typefl.ru — лендинг под рекламу с ограниченным набором ходовых моделей, а не основной сайт завода.
Основание: `01-audit.md`, `05-competitors.md`, `06-lead-engine.md`.
Методика: шаблон B2B-лендинга и модель «дискомфорт – желаемое – путь» из навыка copywriting, раздел о посадочных страницах из cro, анатомия оффера из offers, методика аудита посадочной из yandex-direct.

## 1. Чем лендинг отличается от сайта

| Сайт                                                | Лендинг                                 |
| --------------------------------------------------- | --------------------------------------- |
| много разделов, человек сам ищет нужное             | одна страница ведёт от запроса к заявке |
| навигация по разделам                               | якоря внутри страницы                   |
| каталог всего ассортимента                          | 10 ходовых моделей                      |
| отдельные страницы «О заводе», «Лизинг», «Доставка» | это блоки одной страницы                |
| несколько целей                                     | одна цель: обращение за КП              |

Правило из навыка cro для посадочных: совпадение с объявлением, одно целевое действие, полный довод на одной странице.

## 2. Состав

```
Лендинг (/)
├── 10 страниц моделей (/cisterna-…)      короткие, адреса не меняются
├── Конфигуратор (/konfigurator)           вынесен с главной
├── Спасибо (/spasibo)                     без индексации
├── Политика персональных данных (/privacy-policy)
└── Политика cookie (/cookie)
```

15 страниц. Отдельных страниц каталога, категорий, завода, поставок, лизинга, доставки, контактов и госзаказчиков нет: всё это блоки лендинга.

| Адрес                                                                | Что с ним                                     |
| -------------------------------------------------------------------- | --------------------------------------------- |
| `/`                                                                  | лендинг, переделывается полностью             |
| 10 адресов `/cisterna-…`                                             | остаются, страницы становятся короче          |
| `/leasing`                                                           | переадресация на `/#lizing`                   |
| `/contacts`                                                          | переадресация на `/#kontakty`                 |
| `/konfigurator`                                                      | новая страница, конфигуратор уходит с главной |
| `/spasibo`                                                           | новая, нужна для точного учёта заявок         |
| `/form`, `/test-constructor`, пустая страница, зеркало на `tilda.ws` | удалить или закрыть                           |

Модели: АЦ-10/12, АТЗ-10/12, АЦН-10, АКН-10, АЦВ-10, АЦПТ-10, ППЦ-28, ППЦ-30, ППЦ-32, ППЦ-38. Набор можно сократить, если часть моделей не продаётся.

## 3. Шапка и навигация

**Шапка, закреплённая:** логотип · Модели · В наличии · Как заказать · Лизинг · Вопросы · телефон · почта · Max · кнопка «Получить КП».
Все пункты — якоря лендинга. Со страницы модели они ведут на лендинг к нужному блоку.

**На телефоне:** логотип · телефон в одно касание · кнопка «КП» · бургер с якорями.
**Нижняя панель на телефоне:** Позвонить · Max · Получить КП.

**Подвал:** реквизиты, адреса, политики. Ссылок на другие сайты нет: каждая уводит оплаченного посетителя.

## 4. Совпадение с объявлением без отдельных страниц

Главная проблема из аудита: шесть групп объявлений ведут на один общий экран. Вместо шести посадочных лендинг один, а первый экран подстраивается под группу.

В ссылке объявления стоит метка группы. Небольшой скрипт читает её и меняет заголовок, подзаголовок, фото и порядок моделей. Скрипт собирается в этом проекте и вставляется в Tilda блоком T123.

| Метка    | Группа объявлений           | Что видит человек первым                      |
| -------- | --------------------------- | --------------------------------------------- |
| нет      | общая группа, прямые заходы | общий первый экран, все модели                |
| `g=atz`  | Автотопливозаправщики       | бензовозы и АТЗ, первыми АТЗ-10/12 и АЦ-10/12 |
| `g=ppc`  | Полуприцепы-цистерны        | полуприцепы 28–38 м³, первыми четыре ППЦ      |
| `g=neft` | Автоцистерны для нефти      | нефтевозы, первой АЦН-10                      |
| `g=akn`  | Вакуумные                   | вакуумные автоцистерны, первой АКН-10         |
| `g=voda` | АЦПТ-10                     | водовозы, первыми АЦПТ-10 и АЦВ-10            |

Без метки и при отключённом скрипте показывается общий вариант. Страница остаётся рабочей в любом случае.
Группы под одну модель можно вести сразу на страницу модели.

## 5. Лендинг: блоки по порядку

Порядок следует модели «дискомфорт – желаемое – путь»: сначала человек узнаёт свою ситуацию, потом видит решение, потом понятный шаг.

12 блоков. Ориентир длины: не более 9–10 экранов на телефоне против нынешних 27.
Кнопка заявки есть в блоках 1, 4, 5, 7, 8, 10 и 12, каждый раз со своим текстом, см. `06-lead-engine.md`.

## 6. Оффер

Навык offers требует, чтобы оффер был собран из шести частей. Раньше его части были разбросаны по странице.

| Часть            | Что у нас                                                                                                    |
| ---------------- | ------------------------------------------------------------------------------------------------------------ |
| Основное         | цистерна под задачу заказчика, спецификация согласуется до производства                                      |
| Что входит сверх | комплект ADR, первичная поверка с записью в АРШИН, ПТС и документы, подбор лизинговой компании               |
| Снятие риска     | гарантия 12 месяцев; фото готовой машины до оплаты остатка и отгрузки                                        |
| Почему сейчас    | субсидия до 500 000 ₽ при передаче техники до 30 ноября 2026; скидка 3% до 31 декабря 2026; машины в наличии |
| Название         | «КП с ценой за 1 рабочий день»                                                                               |
| Оплата           | лизинг с авансом от 5% через семь партнёров или прямой договор                                               |

Все поводы «почему сейчас» настоящие, с датами. Выдуманных таймеров и остатков нет: навык offers относит их к приёмам, которые разрушают доверие.

## 7. Страница модели

Короткая посадочная, а не раздел сайта. Сюда приходят с лендинга и по объявлениям под одну модель.

1. Ссылка «Все модели» на лендинг.
2. Первый экран: название словами и индекс, галерея, 4 характеристики, «Цена в КП за 1 рабочий день», гарантия 12 месяцев, кнопки «Получить КП на эту модель» и «Задать вопрос в Max», ссылки «Скачать PDF» и «Распечатать».
3. Для чего модель, 2–3 предложения.
4. Варианты исполнения таблицей.
5. Что входит в поставку.
6. Характеристики, свёрнуты по разделам, рядом чертёж общего вида.
7. Опции.
8. Лизинг одной строкой с плитками партнёров.
9. Похожие модели, три штуки.
10. Форма с названием модели в скрытом поле.

Меню-якоря под шапкой: характеристики · комплектация · опции · лизинг.

## 8. Форма

**Короткая, в попапе и в блоках:** имя · телефон или почта.
**Полная, в блоке 12:** те же поля, плюс необязательные «Организация или ИНН», «Что возите и какой объём», «Прикрепить ТЗ».
Под кнопкой: «КП пришлём за 1 рабочий день. Если оставите телефон, перезвоним в течение 15 минут в рабочее время».
После отправки переход на `/spasibo`.

Почта остаётся равным каналом: 4 из 10 обращений за период пришли письмом.
Подбор, окна и остальной слой захвата описаны в `06-lead-engine.md`.

## 9. Кто что ищет

| Роль                                | Что ищет                                     | Где находит                                     |
| ----------------------------------- | -------------------------------------------- | ----------------------------------------------- |
| Снабженец предприятия               | срок, документы, КП                          | блоки 5, 6, 7, форма                            |
| Специалист по закупкам госзаказчика | КП с реквизитами, документы, соответствие ТЗ | блок 8, полная форма с загрузкой ТЗ, PDF модели |
| Инженер, начальник автоколонны      | характеристики, комплектация                 | страница модели, конфигуратор                   |

Покупатели делятся примерно поровну между частными компаниями и госструктурами. Лендинг общий для обеих групп, различие только в блоке 8 и в полной форме.

## 10. Техника и SEO

- Главное зеркало `https://typefl.ru` без www, с www постоянная переадресация.
- Свои title и description у лендинга и у каждой модели, см. `03-content.md`.
- Один H1 на странице. Опции списком, а не заголовками.
- Alt у всех фото.
- Микроразметка: Organization и FAQPage на лендинге, Product на моделях.
- Убрать Lenis и побуквенную анимацию кнопок, которая задваивает текст.
- Стандартные блоки Tilda там, где они справляются. Самописные вставки из этого проекта: подстройка первого экрана, подбор, переключатель моделей, нижняя панель, конфигуратор.
- Ориентир скорости: главный элемент отрисован до 2,5 секунды на телефоне, HTML страницы до 300 КБ.

Лендинг делается под рекламу. Поисковое продвижение по товарным запросам для него вторично: одна страница не соберёт все запросы.

## 13. Сверка с навыками

**Шаблон B2B-лендинга из copywriting**

| Раздел шаблона                         | Наш блок                                   |
| -------------------------------------- | ------------------------------------------ |
| первый экран с результатом в заголовке | 1                                          |
| полоса доверия                         | 2 и плитки лизинговых партнёров в 10       |
| проблема бизнеса                       | 3                                          |
| решение                                | 4, 6                                       |
| сценарии по ролям                      | 8                                          |
| соответствие требованиям               | 2 и 6: ДОПОГ, АРШИН, документы             |
| партнёры                               | 10                                         |
| кейс с цифрами                         | лента отгрузок в 8; полноценного кейса нет |
| ценность и деньги                      | 10                                         |
| контакт                                | 12                                         |

Слабое место по шаблону: нет кейса с цифрами и нет отзывов. Закрывается только материалами завода.

**Правила посадочной из cro:** совпадение с объявлением — раздел 4; одно целевое действие — обращение за КП; полный довод на одной странице — блоки 1–12; навигация только якорями.

**9 шагов аудита сайта из курса Директа:** шапка с телефоном и закреплением — раздел 3; первый экран с продуктом, географией, акцией и призывом — блоки 1–2; форма до 3 обязательных полей — раздел 8; сертификаты и отзывы — частично, см. выше; окон при входе нет; мобильная панель — раздел 3; цели до запуска — раздел 11; скорость — раздел 10.

**Анатомия оффера из offers:** раздел 6, все шесть частей заполнены.

## 14. Что не вошло

- Отдельные страницы категорий, завода, поставок, доставки, лизинга, госзаказчиков, каталога. Это формат основного сайта.
- Цистерны как навесное оборудование: решение заказчика.
- Цены: решение заказчика.
- Фильтры каталога и сравнение моделей: для 10 моделей хватает переключателя.
- Вторая очередь: видеообзор с владельцем, калькулятор лизинга, кейсы с цифрами, отзывы с Яндекс Карт.
