Методика: навык analytics, раздел аудита кампаний из yandex-direct.

## 1. На какие вопросы должны отвечать данные

1. Сколько обращений даёт каждый рубль рекламы и по каким каналам они приходят.
2. Какая группа объявлений и какой запрос приводят покупателя, а не посетителя.
3. На каком блоке лендинга люди уходят.
4. Какие обращения стали договорами.

Сейчас данные не отвечают ни на первый, ни на четвёртый вопрос: из 10 обращений Метрика видела 5, о двух договорах она не знает.

## 3. События

Имена латиницей со строчных, через подчёркивание, по схеме «объект_действие».

| Событие          | Что означает                     | Параметры                           | Когда срабатывает               | Ключевая цель Директа |
| ---------------- | -------------------------------- | ----------------------------------- | ------------------------------- | --------------------- |
| `kp_form_sent`   | заявка на КП отправлена          | `place`: блок страницы; `model`     | открыта `/spasibo`              | да                    |
| `quiz_started`   | начат подбор                     | `answer_1`                          | клик по первому ответу          | нет                   |
| `quiz_step`      | пройден шаг подбора              | `step`                              | переход к следующему шагу       | нет                   |
| `quiz_sent`      | подбор пройден, контакт оставлен | `product`, `type`, `volume`, `when` | отправка последнего шага        | да                    |
| `config_sent`    | заявка из конфигуратора          | `code`                              | отправка формы конфигуратора    | да                    |
| `stock_request`  | запрос по машине из наличия      | `model`                             | отправка формы из блока наличия | да                    |
| `tender_request` | запрос КП для закупки            | `has_file`                          | отправка формы госзаказчика     | да                    |
| `exit_form_sent` | заявка из окна при уходе         | —                                   | отправка формы окна             | да                    |
| `phone_click`    | клик по телефону                 | `place`                             | автоцель Метрики                | да                    |
| `email_click`    | клик по почте                    | `place`                             | автоцель Метрики                | да                    |
| `max_click`      | переход в Max                    | `place`                             | автоцель Метрики                | да                    |
| `pdf_download`   | скачан PDF модели                | `model`                             | клик по ссылке                  | нет                   |
| `model_view`     | открыта страница модели          | `model`                             | просмотр страницы               | нет                   |
| `cta_click`      | клик по кнопке заявки            | `place`, `text`                     | клик                            | нет                   |
| `block_view`     | блок лендинга попал на экран     | `block`                             | прокрутка до блока              | нет                   |

В параметры не попадают имя, телефон и почта: только сведения о действии.
`block_view` нужен для ответа на третий вопрос. `hero_variant` позволяет сравнить обращения по вариантам первого экрана.

## 5. Звонки, письма, договоры

- **Звонки.** Учёт звонков с подменой номера для посетителей из рекламы. Звонок передаётся в Метрику как цель и становится ключевой целью Директа.
- **Письма.** Отдельный адрес почты только для лендинга. Тогда каждое письмо на него — обращение с лендинга, даже если человек набрал адрес вручную. Сейчас стоит общий адрес отдела продаж на другом домене.
- **Договоры.** Менеджер отмечает в таблице или CRM, какое обращение стало договором. Раз в неделю файл загружается в Метрику как офлайн-конверсия. После этого стратегию Директа можно переключить на оплату за обращения, которые дошли до КП.

## 6. Ключевые цели для стратегии Директа

Оставить: `kp_form_sent`, `quiz_sent`, `config_sent`, `stock_request`, `tender_request`, `exit_form_sent`, `phone_click`, `email_click`, `max_click`, звонок.
Убрать: все «посещения карточек».

Ценность целей назначается одинаковой для всех обращений с контактом и ниже для кликов по телефону, почте и Max: клик ещё не разговор. [НУЖНО: средний чек и доля обращений, доходящих до договора, чтобы посчитать ценность в рублях]

Смену набора целей делать один раз и сразу целиком: каждая правка сбрасывает обучение стратегии.

- [ ] Параметры заполняются.
- [ ] Заявка считается только после реальной отправки, а не по клику на кнопку.
- [ ] Тестовая заявка с каждой формы дошла до отдела продаж.
- [ ] Всё работает на телефоне и в Яндекс Браузере.
- [ ] В параметрах нет личных данных.
